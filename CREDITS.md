# Credits

## Existing group project

The base scene, shader framework, window/input setup, buildings, lamps, and falling snow originate from the group's [Winter Astana by Night repository](https://github.com/Saha1leok/Winter-Astana-by-Night), starting from commit `653c3d2`. Existing source and authorship remain part of that repository's history.

## Member 4 additions

The new river meshes, bank/drift generation, and ice/frost/snow material changes are implemented directly in the project with OpenAI Codex assistance. No third-party models, bitmap textures, shader snippets, or tutorial code were imported for this contribution. The screenshots in `docs/screenshots/` are direct renders of this application.

## Existing dependencies

The contribution uses the same dependencies as the base project: [GLFW](https://www.glfw.org/), [GLEW](https://glew.sourceforge.net/), [GLM](https://github.com/g-truc/glm), and the platform OpenGL implementation. No new runtime dependency was added. Refer to each dependency's distributed license for its terms.

See the AI Use Note in `README.md` and carry the contribution-specific disclosure into the final report.
