# Dilnaz — окна и уличное освещение

Основа: `Saha1leok/Winter-Astana-by-Night`, ветка `main`, commit
`653c3d201637e80911669ffb19938fc0f4e2ca24`, получен 8 ноября 2026.
В этой версии репозитория исходники уже есть. Работа выполнена поверх них.

## Что готово

- 300 окон на четырёх фасадах пяти зданий. Около 67% квартир включены;
  рисунок постоянен между кадрами и запусками, тёплые оттенки немного различаются.
- Выключенные окна остаются тёмными. Смещение от фасада предотвращает z-fighting.
- 12 фонарей вдоль обоих берегов: основание, стойка, светящаяся секция,
  металлическая рама, крышка со снегом.
- Фонари действительно освещают снег и другие поверхности: в GLSL считаются
  расстояние, нормаль поверхности и плавное затухание до радиуса 4.2 единицы.
- Отдельное управление окнами и фонарями; состояния видны в заголовке окна.

Окна используют emissive-цвет. Bloom и свечение в воздухе не реализованы.
У фонарей нет карт теней: объекты не перекрывают их свет.
Лунное освещение исходной сцены остаётся включённым при выключении ламп.

## Показ преподавателю — около минуты

1. Запустить собранную программу (`winter_astana.exe` в Windows,
   `winter_astana` в macOS/Linux). Показать включённые и тёмные квартиры.
2. Нажать **1**: все окна темнеют. Нажать снова: возвращается тот же рисунок.
3. Нажать **2**: гаснут фонари и исчезает тёплая подсветка снега. Повторить.
4. Нажать **L**: всё выключается. Повторить: всё включается.
5. Повернуть камеру левой кнопкой мыши, приблизить колёсиком. **Esc** — выход.

Клавиши переключают состояние только при первом нажатии; удержание не вызывает мигание.
Если одна группа включена, **L** выключает обе. Если обе выключены, **L** включает обе.

## Сборка

Требуются CMake 3.16+, компилятор C++17 и драйвер OpenGL 3.3.
Для автоматической загрузки зафиксированных версий GLFW 3.4, GLEW 2.2.0 и GLM 1.0.1
нужны Git и интернет при первой конфигурации:

```powershell
cmake -S . -B build -DWINTER_ASTANA_FETCH_DEPS=ON
cmake --build build --config Release --parallel
```

Visual Studio: `./build/Release/winter_astana.exe`.
MinGW и одноконфигурационные генераторы: `./build/winter_astana.exe`.
macOS/Linux: `./build/winter_astana`.
Запускайте из корня проекта или из каталога с исполняемым файлом.
Каталог `shaders` копируется рядом с программой автоматически.

Для установленных GLFW/GLEW/GLM, включая vcpkg, оставьте
`WINTER_ASTANA_FETCH_DEPS=OFF` и используйте исходные инструкции README.
Используйте отдельный каталог сборки при смене компилятора/способа установки зависимостей.

## Интеграция и дальнейшая работа над локацией

Освещение встроено в текущую черновую локацию. Это промежуточный результат Dilnaz:
после изменения зданий и берегов нужно проверить размещение окон и фонарей.
Позиции фонарей вычисляются по `riverCenter`, `riverHalfWidth` и `snowHeight`;
генерация окон использует массивы центров и размеров зданий в `main.cpp`.
Геометрия освещения создаётся один раз при запуске. Для изменения локации во время
работы программы потребуется пересоздать соответствующие данные.

Изменённые и добавленные компоненты:

- `Lighting.h/.cpp`: данные окон, воспроизводимая генерация, загрузка позиций фонарей.
- `main.cpp`: один раз создаёт окна и лампы; регистрирует обработчик клавиш;
  перед отрисовкой поверхностей вызывает `uploadLamps`; рисует окна и фонари.
- `scene.frag`: массив точечных источников и их вклад в освещение.
- `CMakeLists.txt`: добавляет `Lighting.cpp`, необязательную загрузку зависимостей и CTest.
- `FrameCapture.h`: запись BMP для проверки рендеринга.

Для новых зданий передавайте мировой центр и размеры в `buildingWindows`.
Текущий генератор рассчитан на прямоугольные здания без поворота.
Лимит фонарей — 12; для расширения синхронно измените `maxLamps` и `MAX_LAMPS`.

## Проверки

Выполнены в Windows: GCC 15.2, Release, CMake 4.4, контекст OpenGL 3.3 Core.
Код проекта собран с `-Wall -Wextra -Wpedantic` без предупреждений.
У старых CMake-файлов зависимостей есть предупреждения о совместимости CMake;
они не мешают сборке.

```powershell
ctest --test-dir build -C Release --output-on-failure
```

Тест создаёт невидимое окно с настоящим OpenGL-контекстом, компилирует и линкует
GLSL, проверяет наличие включённых и выключенных квартир, игнорирование повтора
клавиши, все четыре комбинации освещения и повторное включение через L.
После каждого кадра проверяется `glGetError` и сохраняется BMP в `build/lighting-captures`.
Для теста нужен доступный графический контекст; это не тест для сервера без GPU/дисплея.

Ручной запуск того же теста:

```powershell
./build/winter_astana.exe --smoke-test captures
```

Снимки «всё включено» и «всё выключено» просмотрены. Работа мыши,
производительность на других видеокартах и сборка на Linux/macOS отдельно не проверялись.
